# Contributor Covenant Code of Conduct

This project follows the Contributor Covenant Code of Conduct. We expect all contributors to adhere to it.

Our standards:
- Be respectful, kind, and considerate.
- Be inclusive and welcoming to newcomers.
- Avoid harassment, discriminatory language, or personal attacks.

Report unacceptable behavior to: stephen-wu-chaohui (via GitHub) or email (add an email address if you prefer).

For the full text of the Contributor Covenant, see:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/
